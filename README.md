# FotoAtmiņa — publiska apskates versija

Šis zars satur tikai statisko mājaslapu un publiskos AI attēlu piemērus. Klientu dati, pārvaldes panelis, paroles un servera konfigurācija šeit nav iekļauti.

- Trīs foto piemēri ir AI veidoti demonstrācijas attēli.
- “Izmēģināt ar paraugu” rāda iepriekš sagatavotu krāsaino attēlu; tā ir marķēta demonstrācija.
- “Iekrāsot fotogrāfiju ar AI” un “Iekrāsot paraugu ar AI” veic īstu DDColor modeļa apstrādi lokāli pārlūkā. Foto netiek sūtīts serverim. Pirmā modeļa lejupielāde ir aptuveni 130 MB.
- Pieteikumu nosūtīšana restaurācijas pakalpojumam šajā statiskajā versijā ir izslēgta.
- “Privātums” apraksta lokālo apstrādi un modeļa lejupielādi.

Publicēšanai: repozitorija Settings → Pages → Deploy from a branch → main → /(root). Šis ir publisks repozitorijs tikai apskates lapai. Pilnais projekts paliek atsevišķā privātā repozitorijā.

Apskates adrese pēc Pages ieslēgšanas: https://edvins99.github.io/fotoatmina-demo/
